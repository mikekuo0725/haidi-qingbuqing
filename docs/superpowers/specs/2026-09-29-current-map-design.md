# 海流地圖 設計

2026-09-29 · Michael 定案

## 要做什麼

主畫面加一張潛點小地圖，上面有分區燈號點和一支「整片海往哪流」的大箭頭。地圖下面一條時間軸，拖到哪個小時，箭頭就轉到那個小時的方向和速度。

## 已經決定的事

- **一支大箭頭，不是每區一支**。Open-Meteo 海流約 10 公里一格，整座小琉球在同一格。每區各畫一支會讓人以為是分開量的。
- **有時間軸**。同一天流向會轉（例：9/30 小琉球早上往南、中午往西南、下午往東南）。
- **自己畫的簡單地圖，不用線上地圖**。海岸線事先從 OpenStreetMap 抓一次，存成資料。好處：輕、船上沒訊號也能看、大太陽下清楚。缺點：不能放大、沒有路名。
- **一直顯示，放在分區卡片上面**，取代現在「🌀 海流」那一格。

## 畫面

- 地圖：海藍色底、陸地米黃色、真的海岸線。
- 每個分區一個圓點，顏色 = 那區的燈號（紫/綠/黃/紅/灰），點上方寫區名。點圓點 = 點那區的卡片（進細節頁）。
- 右上角小框：大箭頭 + 「往西南」+「0.16 節」+ 小字「整片海的大概流向」。箭頭顏色跟那個小時的流速燈號（綠/黃/紅，門檻用潛點的 `safety.currentYellowKn` / `currentRedKn`）。
- 地圖下面：「⏰ 10:00 的海流」+ 滑桿。範圍 **8 點到 16 點**（預測資料本來就只算這 9 個小時）。一開始停在「最佳下水」的第一個小時。
- 滑桿下面一行：「這天最強：0.81 節 → 往東南 🟡 注意」（就是原本那一格的文字，保留安全提醒）。
- 換日期分頁、換潛點時，滑桿回到最佳下水時間。其他資料晚到時重畫畫面，滑桿停在使用者拖到的位置。
- 水溫、最佳下水、浪、大浪警告、湧升流警告照舊，放在地圖下面。
- 電腦寬螢幕：地圖最寬 480px 置中。

### 3 個潛點

| 潛點 | 地圖範圍（南西 → 北東） | 內容 |
|---|---|---|
| 小琉球 | 22.31,120.335 → 22.37,120.405 | 整座島 + 4 點 |
| 墾丁 | 21.89,120.68 → 22.02,120.87 | 恆春半島南端 + 3 點。海岸線是一條開口的線，往北用範圍外的兩個點補成一塊陸地 |
| 七星岩 | 21.745,120.805 → 21.773,120.845 | 大部分是海 + 2 點。OpenStreetMap 有礁石就畫，沒有就只有點。左下角小字「鵝鑾鼻在北邊約 16 公里」 |

七星岩兩點只差 670 公尺，要看得出是兩個點，所以不把鵝鑾鼻畫進來（範圍要放大到 20 公里，兩點會疊在一起）。

## 技術

- `src/core/mapProject.js`：小範圍平面投影。寬固定 300，高照範圍比例算。`project(bbox, [lat, lon]) → [x, y]`、`mapHeight(bbox)`。
- `buildForecast` 多回傳 `currents`：每小時 `{ hour, kn, toDeg, level }`。天氣資料本來就有，不用多抓。
- 海岸線資料：`src/data/spots/maps/<id>.json` = `{ bbox, land: [SVG path 字串...], note? }`，由 `scripts/coastline.mjs` 產生（Overpass API 抓 `natural=coastline`，接起來、補成封閉、投影、每 1.5px 取一點）。地圖資料**不放進潛點 JSON**，衛星小幫手（Worker）也讀潛點 JSON，不需要地圖。
- `src/ui/seaMap.js`：`renderSeaMap(...)` 產生 HTML、`currentBadge(c)` 產生右上角小框、`updateSeaMap(root, c)` 拖滑桿時只換小框和時間字，不重畫整頁。
- `renderMain` 多收 `map`、`mapHour`。沒有地圖資料的潛點 → 顯示原本的「🌀 海流」格子（以後加潛點忘了跑腳本也不會壞）。
- `main.js`：`state.mapHour`、滑桿 `input` 事件、點地圖圓點進細節頁。
- 地圖圓點用 `data-mapzone`，不用 `data-zone`（卡片順序測試靠 `data-zone`）。

## 出錯怎麼辦

- 沒有地圖資料 → 舊的海流格子。
- 這天沒有預測 → 跟現在一樣顯示「這天沒有資料」，不畫地圖。
- 天氣太舊（灰燈）→ 地圖照畫，圓點灰色。

## 測試

- 投影：四個角落、小琉球高度。
- 海岸線工具：接線、補封閉、轉 path（純函式，不連網路）。
- `currents`：9 個小時、節數換算、燈號門檻。
- 地圖資料：每個潛點都有、每個分區點都在範圍內、path 格式對。
- `renderSeaMap`：每區一個圓點且顏色對、滑桿預設在最佳下水、箭頭角度、沒地圖時的舊格子。
- 手動：本機開網頁，3 個潛點都看一次，拖滑桿、點圓點、換日期、窄螢幕 320px 不左右滑。

## 不做

- 每區各自的流、繞島的流（資料做不到）。
- 可以放大縮小的地圖、路名、港口。
- 8 點前、16 點後的流。
